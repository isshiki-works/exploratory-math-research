# 未解決の数学問題を探究するためのスキル

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語

未解決の数学問題に取り組むための実験的なエージェントスキルです。元の問題を保ち、自ら課した制約を見直し、早すぎる断念、目標のずれ、エージェント間の引き継ぎに伴う目的の喪失を減らすことを目指します。

内部での試用から得た研究上の助言と具体例をまとめたもので、有効性を測る対照評価はまだ行っていません。

## 提供するもの

- ユーザーの目標と、モデルが選んだ表現、中間補題、成果物の形式を区別するための指針。
- どの条件が失敗したかを調べ、失敗した構成から次の具体的な数学的作業につなぐ方法。
- 高コストな計算、補助的な開発、元の問題から離れた証明に進む前の簡単な比較。
- 許可された分担と引き継ぎの際に、元の用途、数式、成立した事実、失敗の範囲を保つための助言。

実際の未解決問題の探究や、その後の研究判断に影響する振り返り・検討を対象とします。通常の演習、会話の整理、研究判断を伴わない文献要約には、通常このスキルは必要ありません。

## 使い方

コミュニティの skills CLI で GitHub からインストールできます。

```sh
npx skills add isshiki-works/exploratory-math-research
```

または、`exploratory-math-research` フォルダ全体を、利用するエージェントが認識する skills ディレクトリに置きます。`SKILL.md` はフォルダの直下に置いてください。名前でスキルを呼び出せる環境では、例えば次のように依頼できます。

```text
$exploratory-math-research を使い、次の問題を研究してください。
[問題の原文、許される仮定、既存の作業、資源の上限]
```

振り返りだけが必要なら、研究の再開ではなく振り返りを依頼してください。スキル自体は、追加エージェント、外部への操作、予算の拡大を許可するものではありません。

既定の入口は[中国語原文](SKILL.zh-CN.md)です。実行方法と18件の中核事例をすべて含む[英語版](SKILL.en.md)と[日本語版](SKILL.ja.md)もあります。別の言語を入口にする場合は、**インストール用のコピー内で**該当ファイルを `SKILL.md` にコピーし、ほかのファイルを残してください。任意の表示用メタデータは `agents/openai.en.yaml` と `agents/openai.ja.yaml` にあり、必要なら該当ファイルで `agents/openai.yaml` を置き換えます。既存のインストールを変更する前にバックアップを残してください。

詳細な[研究史ノート](references/discovery/index.md)は現在中国語のみです。中核事例を補足する資料であり、全体の翻訳はまだ行っていません。スキルの閲覧に実行環境の依存関係はありません。実際の研究で必要なツールは課題によって異なります。

## 作者の声明

一色（Isshiki）

SF作家として、私は未解決問題について内部で繰り返し研究する中で、このスキルを作りました。そこには、ヤコビアン問題に関する研究を、条件を限定して再現する試みも含まれます。その過程で、モデルの早すぎる断念、目標のずれ、エージェント間の引き継ぎ設計に伴う損失に、一定の反復パターンがあることを観察し、Astraと共に軽減を試みました。選んだ歴史的事例から抽出した、具体的で細かな数学的作業の提案を含む初期的な取り組みとして公開します。実際の未解決問題に、より適したものです。

それでも、最初の方向をより正確に選び、適切なところに賭けることに依存します。つまり、研究機関が持つ優位性は、その研究が非効率であったとしても、この種のプロンプトでは埋められません。さらに細かな発見のための指針を与えても、あらゆる経路を段階的に捉え尽くすことはできません。明らかに不合理に見える投入や誤りを、できる限り減らそうとするだけです。ただし、退けたものが実は正しい可能性も排除できません。その上で、現在利用できるモデルが関連する研究方針を選ぶ力を改善し、早すぎる断念や、回答を出すためだけに無関係な証明へ過度に入り込むことを減らせればと考えています。

効果を識別できるA/Bテストを、完全には実施できていません。Ponytailを評価するように、このスキルが実際にどれだけ改善をもたらすかを測るには、多くのトークンが必要です。現在、包括的な検証のために十分な計算資源を確保する余力も計画もありません。複数の内部的な未解決数学問題への挑戦から経験と教訓を抽出したものですが、私たちはこれを使って当初解決したいと考えた問題を解決できませんでした。それでも、小規模に行ったヤコビアン問題の再現で見られた成功と失敗のパターンは、こうした問題が存在することを初歩的に裏付けています。

2026年9月8日、OpenAIはNavier–Stokes方程式の存在と滑らかさの問題に対する解答を発表し、論文とLeanによる形式化を公開しました。これは、このスキル全体と私の関連する活動で予見してきたことが、最も顕著に現実となった出来事に近いと感じます。初期からのAI利用者として、SF作家として、私はこうした発展に不安を感じています。特に、最先端の知識をコントロールする力が、少数の巨大AI企業に前例のない形で集中することを懸念しています。

この作業が、スキルを使い、問い直し、共に育てようとするすべての人の助けになればと願っています。その多くは、人間の数学的な知恵と長年の蓄積に由来します。時代が変わる今、人々が力を合わせ、すでに得られた成果や経験をできる限り共有し、無益な浪費や閉鎖性を減らしてほしいと願っています。そして、共に新しい現実に向き合いたいと思います。新しい時代は未来にあるのではなく、今この瞬間から始まるのです。
