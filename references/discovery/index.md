# 研究判断的案例与来源

[综合认识](overview.md)讨论方向、线索、工具和失败解释怎样在研究中变化。以下索引按实际过程描述材料，不是对新问题的预先分类，也不规定阅读顺序。原始论文和同期讨论链接保存在各篇材料中；这些文件是有来源的研究笔记，不是所有原文的完整副本。

## 有连续记录的中间过程

| 材料 | 其中发生的变化 |
|---|---|
| [EDP 的联系逐渐形成](inputs/entropy-decrement-construction.md) | 松散联想、直接应用的异议、后来形成的连接，以及不再必须解决的强图扩张子目标 |
| [Polymath1 重新解释已有论证](inputs/polymath-concept-emergence.md) | 不能确定是未理解还是存在漏洞；density 与 mass 的区别逐渐明确 |
| [Hilbert 第十问题中改变了的构造](inputs/hilbert10-reconsideration.md) | 起初以为沿用原方案，后来发现周期关系与困难分布已变；区分书信、回忆和数学切面 |
| [未闭合的 EDP 分支](inputs/edp-failed-middle.md) | 数值希望、具体反例与新候选；保留没有成功结局的部分 |
| [Bend2 的内存流动](inputs/taelin-bend2.md) | 局部机制诊断未决定干预位置；直方图与调度知识促成轮换绑定，原帖转贴的摘要与分析，原帖 URL 待核对 |
| [从负指数路线到零点比例](inputs/riemann-inertia-turns.md) | 纠正失败对象、改变惯性不等式的用途、删除父任务的中间要求，以及发表版本对局部限制的再次修正 |
